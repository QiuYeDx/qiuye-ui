# QiuYe UI Pitfall Guard

Use this skill when modifying reusable components, Motion behavior, registry
artifacts, build validation, or visual QA in this repository.

## Required workflow

1. Read `references/index.md` first.
2. Match the task against the index by area, triggers, symptoms, files, and commands.
3. Read only the relevant detail files.
4. Apply their Do, Avoid, and Validation guidance.
5. Add or update a focused pitfall when the task reveals a reusable repository lesson.

Keep the index concise and store one lesson per detail file.
